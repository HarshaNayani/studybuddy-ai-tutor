# Quadratic Equations

A quadratic equation has the form ax^2 + bx + c = 0 with a not equal to 0.

## Quadratic formula
x = (-b +/- sqrt(b^2 - 4ac)) / (2a)

## Discriminant
D = b^2 - 4ac. If D > 0 there are two distinct real roots. If D = 0 there is one repeated root. If D < 0 there are no real roots.

## Example
Solve x^2 - 5x + 6 = 0. Here a=1, b=-5, c=6, D = 25 - 24 = 1. Roots: x = (5 +/- 1) / 2, so x = 3 or x = 2. Check by factoring: (x-2)(x-3) = 0.

## Other methods
Factoring, completing the square, and graphing (roots are where the parabola crosses the x-axis).
